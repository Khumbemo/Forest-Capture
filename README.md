# Forest-Logger
A forest survey app streamlines fieldwork by guiding users through structured data collection. It records species, growth stages, measurements, environmental factors, disturbances, and fire impact (CBI). With offline access, photos, and notes, it helps researchers stay organized, reduce errors, and focus on observation.

## Building

`www/` is a generated build artifact (not tracked in git) — run `npm run prep` (or `npm run cap:sync` to also sync the Android project) to regenerate it from `index.html`, `src/`, `vendor/`, and `data/` before opening the Android project or serving locally with `npm start`.
